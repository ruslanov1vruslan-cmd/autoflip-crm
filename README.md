# AutoFlip CRM — PWA

Это готовая PWA-версия AutoFlip CRM.

## Что внутри
- `index.html` — приложение.
- `manifest.webmanifest` — настройки установки на телефон.
- `sw.js` — офлайн-кэш.
- `icons/` — иконки приложения.

## Важно
Для установки как PWA приложение должно открываться через HTTPS (или локально через localhost). При открытии файла напрямую через `file://` manifest и service worker не работают как полноценная PWA.

## Вариант публикации через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи содержимое этой папки в корень репозитория.
3. Включи GitHub Pages для репозитория.
4. Открой опубликованный HTTPS-адрес на iPhone в Safari.
5. Нажми «Поделиться» → «На экран "Домой"».

## Подключение Google Sheets
После публикации открой CRM:
Настройки → Google Sheets / Apps Script.

Вставь:
- URL Web App `/exec`;
- API key.

Затем нажми «Синхронизировать сейчас».

## Важно про приватность
GitHub Pages публикует сайт в интернете. В репозитории нет твоих локальных CRM-данных и API key, если ты не записал их прямо в код.
Данные CRM хранятся в localStorage браузера конкретного устройства.
